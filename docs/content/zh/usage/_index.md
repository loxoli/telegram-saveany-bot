# 使用說明

這裡介紹 Save Any Bot 的一些功能和使用方法, 如果您沒有在這裡找到所需的內容, 另請參閱 [設定說明](../deployment/configuration) 或前往 Github [Discussions](https://github.com/krau/SaveAny-Bot/discussions) 提問.

## 轉存檔案

要使用 Bot 的轉存 Telegram 檔案功能, 需要向 Bot 傳送或轉發以下類型的訊息.

1. 檔案或媒體訊息, 如圖片、影片、文件等
2. Telegram 訊息連結, 例如: `https://t.me/acherkrau/1097`. **即使頻道禁止了轉發和儲存, Bot 依然可以下載其檔案.**
3. Telegra.ph 的文章連結, Bot 將下載其中的所有圖片
